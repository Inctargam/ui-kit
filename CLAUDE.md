# CLAUDE.md

Указатель для Claude Code. Паспорт кита, соглашения и правила разработки — в
[CONTRIBUTING.md](./CONTRIBUTING.md), он трекается и его читают все контрибьюторы.

## Что за проект

`@remark-gram/ui-kit` — библиотека UI-компонентов на **Base UI + CSS Modules**, React 19,
TypeScript. Вынос компонентов из `src/shared/ui` основного проекта `remark-gram` в
отдельный версионируемый пакет. Vite (library mode, ESM, `preserveModules`) + Storybook 10,
тесты — Vitest 4 в browser mode (стори работают как тесты).

18 компонентов, 90 иконок. Состояние этапов — в `ROADMAP.md` (локальный): этапы 0–8
закрыты, следующая веха — этап 9 (перевод `remark-gram` на токены и компоненты кита).

## Читать первым

- **[CONTRIBUTING.md](./CONTRIBUTING.md)** — архитектура, сборка пакета, соглашения
  (стили/токены/компоненты/иконки/Storybook/TS), тесты, формат коммитов, правила
  changeset, релиз.
- **[README.md](./README.md)** — публичный API для потребителя пакета.
- **[MIGRATIONS.md](./MIGRATIONS.md)** — разбор каждого переноса из `remark-gram`.
  Единственное место для этого; формат — строка на факт (`± правка`, `+ токен`,
  `− не перенесено`), без прозы.

## Обязательное после задачи

1. `pnpm build` — чинить до зелёной сборки.
2. `pnpm format` (Prettier, `printWidth: 120`).
3. Коммиты — Conventional Commits, без подписи (детали — в CONTRIBUTING.md).
4. Правка, видимая потребителю (компонент, токен, публичный API) → `pnpm changeset`,
   описание в тот же PR. Правки репозитория (CI, доки, тесты, конфиги) — без описания.
5. Если это перенос — блок по батчу в `MIGRATIONS.md`.

## Рабочие заметки (в `.gitignore`, локальные)

- **`LOG.md`** — в начале сессии запись из трёх строк: `## [дата] — [что делали]`,
  `**Цель:**`, `**Осталось:**`. Без пересказа решений (они в `MIGRATIONS.md`).
- **`TODO.md`** — план и статус текущих работ.
- **`QA.md`** — вопросы-ответы **одной записью в конце сессии** (файл большой,
  открывать на каждый вопрос дорого). Если вопрос написан прямо в `QA.md` — ответить там же.
- **`ROADMAP.md`** — план этапов, обоснования принятых решений, точный путь к чекауту
  `remark-gram`.

Форматы записей — в глобальном `~/.claude/CLAUDE.md`.

## Источник компонентов

Соседний чекаут `remark-gram` (Next 16, FSD, Base UI + CSS Modules; точный путь — в
`ROADMAP.md`). Дизайн-система — `STYLES.md` там же, токены — `src/app/styles/tokens.css`.
**Приложение живёт своей жизнью** и добавляет компоненты в `shared/ui` — перед новым
батчем сверять список папок `src/shared/ui` с `src/components/` кита.

## MCP-серверы

- **context7** — документация библиотек/фреймворков/CLI берётся оттуда, не из памяти.
- **shadcn** — если в промте упомянут Shadcn. **В этом проекте не применяется:**
  кит на Base UI + CSS Modules.
- **Figma** — если упомянута Figma. **Не применяется:** дизайн-система уже выгружена
  в `STYLES.md` основного проекта.

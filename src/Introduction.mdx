# @remark-gram/ui-kit

Библиотека UI-компонентов основного приложения: **Base UI + CSS Modules**, React 19,
TypeScript. Вынесена из `src/shared/ui`, чтобы её можно было переиспользовать и версионировать
отдельно.

18 компонентов и 90 иконок. Тёмная тема по умолчанию, доступность и клавиатура — на
примитивах Base UI, стилизация — CSS Modules с состояниями через `[data-*]`.

## Установка

```bash
pnpm add @remark-gram/ui-kit
```

`@base-ui/react`, `react`, `react-dom` — peer-зависимости, ставятся отдельно.

## Подключение стилей

Импортировать один раз в корне приложения, в этом порядке:

```ts
import '@remark-gram/ui-kit/styles/tokens.css' // обязательно — палитра, размеры, отступы
import '@remark-gram/ui-kit/styles.css' // обязательно — собранные стили компонентов
import '@remark-gram/ui-kit/styles/reset.css' // по желанию — глобальный сброс
```

Без `tokens.css` компоненты останутся без цветов и размеров: всё оформление внутри — это
`var(--…)`, брать переменные больше неоткуда.

## Использование

```tsx
import { Button, Input, BellOutlineIcon } from '@remark-gram/ui-kit'

;<Button variant="primary">
  <BellOutlineIcon size={16} /> Готово
</Button>
```

Иконки — именованные экспорты (`<BellOutlineIcon />`), не строковый `id`. Tree-shaking
честный: в бандл попадают только взятые.

## Что где в витрине

- **Foundations** — токены дизайн-системы (палитра, семантика, типографика, отступы)
  и полный набор иконок.
- **Components** — компоненты кита. У каждого вкладка **Docs** с таблицей пропсов
  и примерами, вкладка **Canvas** с песочницей на контролах.

Переключатель фона в тулбаре (тёмный / светлый) — это **не** смена темы: светлого набора
токенов в дизайн-системе нет. Он инвертирует поверхность холста, чтобы поймать глазами
ошибку в паре токенов и проверить контраст.
